Pasang di Android

Ikuti langkah berikut untuk memasang aplikasi.

  1. Ketuk Unduh APK di bawah. Jika muncul peringatan, pilih Tetap unduh.
  2. Buka file adiwiyata.apk dari notifikasi atau folder Unduhan.
  3. Jika diminta, aktifkan Izinkan dari sumber ini di Pengaturan, lalu kembali.
  4. Ketuk Instal, lalu Buka aplikasi.
File ini di luar Play Store, jadi Android akan meminta izin instal. Unduh hanya dari halaman resmi sekolah.

Pasang di iPhone

iOS punya cara pemasangan yang berbeda dari Android.

  1. Buka halaman ini di Safari.
  2. Ketuk tombol Bagikan (kotak dengan panah ke atas).
  3. Pilih Tambah ke Layar Utama, lalu Tambah.
